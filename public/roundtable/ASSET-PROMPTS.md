# Agent 圆桌场景素材

当前可运行版使用项目内置的蓝白 SVG 场景和四帧 SVG 角色图集，不依赖外部密钥。以下保留 GPT Image 替换版的生成规范；日后生成同名 PNG 后，可在 CSS 中切换资源地址。

## 通用规范

- Use case: `stylized-concept`
- Asset type: wide game environment background for a web Agent roundtable
- Style: polished 3D clay diorama, premium friendly strategy game, rounded handmade forms
- Composition: 16:9 wide, slightly elevated isometric camera, open center floor for an HTML oval table and four Agent seats
- Palette: white, pale blue, cobalt accents, restrained mint accents
- Constraints: no people, no characters, no table in the center, no readable text, no logos, no watermark, no UI panels
- Output: `2048x1152`, PNG, `gpt-image-2`, quality high
