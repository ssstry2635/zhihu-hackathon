# zhihu-hackathon
这是为了参加2026知乎黑客松的仓库，项目名称为见山另一面。“见山另一面”是一款基于知乎真实内容的 AI 观点社交产品。 产品可以将知乎问题下基于不同角度、不同观点的回答及精选评论进行分类。用户可以进入分类后的讨论区，与关心同一议题、同一讨论角度的用户进行高质量深度交流；也可以进入 Agent 圆桌，通过一组代表不同观点立场的 Agent 进行有组织的讨论，快速理解不同观点的核心主张、争执过程与真正分歧。 当用户打开一个回答较多、观点复杂的知乎问题时，可以启动“见山另一面”。AI 将当前采集到的回答和精选评论，按照讨论角度、观点立场与核心论据整理为不同讨论区。用户不必在混杂的信息中反复筛选，可以直接进入自己关心的区域深入讨论。 产品的本质，是将讨论中的“共识”与“争论”分离。
