## 导航故障回归

线上已复现 next/link 点击时抛出 TypeError，停留原页；与知乎凭证无关。修复采用原生页面链接与分析完成后的 document 导航。新增 scripts/navigation-checks.mjs 覆盖导航栏、圆桌入口、播放/暂停、来源弹窗、补充问题、分类讨论区及主按钮，并要求无 JavaScript 运行错误。


线上验证：2026-09-08，修复已发布到原私有 Demo（Sites 第 2 版）。使用隔离 Chrome 对部署后的页面完成真实点击检查：

- 首页导航进入 Agent 圆桌。
- 下一条发言、播放/暂停、查看完整讨论，共 8 条预置发言。
- 查看来源并关闭弹窗。
- 圆桌待解问题跳转到对应讨论区，保留 analysis 和 gap 参数。
- 总览进入分类讨论区、返回总览、总览进入圆桌。
- 返回问题现场，点击主按钮进入观点总览。
- 本轮浏览器 JavaScript 运行错误：0。

测试仅使用预置样本，没有发布用户帖子，也没有调用知乎模型。运行记录保存在 work/online-validation.json（本地，不包含访问凭证）。完整检查逻辑见 scripts/navigation-checks.mjs。

本地环境说明：此前本地 Miniflare 生产预览曾在后续页面请求上长时间等待并出现 Network connection lost；真实部署后的同一套点击检查已通过。本次不将本地运行时问题报告为线上应用故障，也未通过改写接口响应来让测试通过。
